# Homebrew tap for otok

[otok](https://github.com/otok-dev/otok) is a dependency manager that builds native libraries from source on
your machine and hands them to your build.

## Install

```sh
brew install otok-dev/tap/otok
```

or

```sh
brew tap otok-dev/tap
brew install otok
```

The latest development version: `brew install --HEAD otok-dev/tap/otok`.

## Update

```sh
brew update
brew upgrade otok
```
